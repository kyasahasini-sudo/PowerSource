How minimum-cost wiring worksExplore MSTs, Prim's algorithm, and the cut property

A minimum spanning tree connects every reachable location using the least total wire, without creating unnecessary loops. Prim's grows one connected network outward from the power source.

01 / StartMark the source as powered. Every other location is still outside the tree.
02 / ChooseAmong all wires crossing from powered to unpowered locations, select the cheapest.
03 / ExpandAdd that wire and new building. Repeat until every reachable building is powered.
Why this is minimum: At each iteration, the chosen wire is the cheapest one crossing the boundary between powered and unpowered locations. The cut property says that wire is safe to include in some minimum spanning tree, so repeating the choice builds an overall minimum-cost result.
